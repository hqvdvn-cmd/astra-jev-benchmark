# Повторы попыток после ограничений

По просьбе владельца три попытки выполнены повторно с чистого стартера. Модели, промпт, зависимости, xhigh и лимит900секунд сохранены.17остальных результатов не менялись, включая ошибку мобильной вёрстки Astra + Jev.

Это отдельная редакция сравнения с повторами. Исходная полная серия сохранена в original-snapshot; её результаты: Astra4/5, Astra + Jev3/5, Sol4/5, Sol + Jev5/5. Новые исходы используются независимо от успеха; повторный тайм-аут не вызывает бесконечных перезапусков.

| Режим | Исходная серия | После повторов |
| --- | ---: | ---: |
| gpt-6-astra/baseline | 4/5 | 4/5 |
| gpt-6-astra/jev_offload | 3/5 | 4/5 |
| gpt-6.1-sol/baseline | 4/5 | 4/5 |
| gpt-6.1-sol/jev_offload | 5/5 | 5/5 |

Повторённые ячейки:

- gpt-6-astra-baseline-r1: лимит времени; проверки5/18; генерация900.2с.
- gpt-6-astra-jev_offload-r2: успех; проверки18/18; генерация763.8с.
- gpt-6.1-sol-baseline-r5: лимит времени; проверки18/18; генерация900.2с.

Два исходных тайм-аута не содержали явной ошибки квоты. Третий также содержал403и обрывы соединения. Пять других явных прерываний по квоте/авторизации уже были заменены в первой серии; их архив сохранён.

Медиана времени группы Sol + Jev остаётся недоступной: у одного раннего успешного прогона время потеряно при остановке вызывающего процесса. Фактическая стоимость CLI неизвестна. Проверки подтверждают перечисленные функции, а визуальное качество не сведено в автоматический балл. Пять повторов одного задания не доказывают общего преимущества модели или Jev.
